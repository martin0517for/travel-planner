# Travel Planner — Phase 1 骨架

## 給要維護這個專案的人

要修改這個專案之前，先看 **`MAINTENANCE.md`**——裡面詳細列出：
- 需要具備哪些 HTML／CSS／JavaScript 知識（附對照表，標出每個語法出現在哪個檔案）
- 專案的三層架構（View → Service → Repository）為什麼要這樣分
- 全專案重複使用的三種程式碼模式，看懂範例檔案，其他 40 幾個檔案幾乎都是同一套寫法
- 資料模型之間怎麼關聯
- 常見維護情境的操作步驟（加欄位、加新資料類型、改樣式、除錯）

程式碼本身也都補上了注釋：每個檔案開頭有一段說明「這個檔案是做什麼的」，
關鍵邏輯（路由、資料存取、ID 重新對應等）也有行內注釋解釋在做什麼、為什麼這樣做。

## 如何啟動

這個專案用原生 ES Modules（`import`/`export`），瀏覽器基於安全性限制，**無法直接用 `file://` 開啟 `index.html`**，需要透過一個簡單的本機伺服器：

```bash
# 方法一：Node 內建（若已安裝 Node.js）
npx serve .

# 方法二：Python（若已安裝 Python 3）
python3 -m http.server 5500
```

啟動後用瀏覽器開啟顯示的網址（例如 `http://localhost:5500`）。

之後要部署，直接把整個資料夾上傳到 Netlify（拖曳資料夾到 Netlify Drop 即可），因為它本來就是純靜態檔案。
